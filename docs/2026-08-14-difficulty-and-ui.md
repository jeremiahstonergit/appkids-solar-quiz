# 14.08.2026 — уровни сложности и UX сортировки

- Источник вопросов: `Солнечная система_корабли_космодромы_космонавты.xlsm`, 78 вопросов.
- В каждой игровой сессии по-прежнему 12 вопросов: по 2 случайных вопроса каждой из 6 механик.
- В начале пользователь выбирает уровень: 1 — легкий (2–4), 2 — средний (4–6), 3 — сложный (6+).
- Для каждого уровня в каждой механике есть минимум 4 вопроса, поэтому выборка 2 вопросов всегда возможна.
- Сортировка: после переноса текущий объект сразу скрывается; зеленым/красным подсвечивается только выбранная зона. Названия левой/правой категории выводятся явно.
- Числовые варианты ответа 6/7/8/9 показываются одной крупной цифрой без дублирующей подписи и декоративного круга.
- `Правда/Ложь` использует формулировку `Ложь`, совпадающую с базой.
- Визуальные подписи объектов находятся в HTML отдельно от изображения. Контентные изображения в S3 должны быть без встроенных текстовых подписей.

Таблица со сложностью подготовлена отдельно как `Солнечная_система_вопросы_со_сложностью.xlsx`.
